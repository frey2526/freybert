# Sobre mí

Soy Freybert. Construyo automatizaciones que resuelven cosas concretas: lanzar tareas, vigilar que salgan bien y enseñar el resultado en una pantalla.

Vengo de Python y Git, y estoy aprendiendo lo que rodea al producto: HTML y CSS, JavaScript, APIs con FastAPI, SQL y despliegue. Me interesa lo que se puede tocar: paneles, formularios, páginas.
