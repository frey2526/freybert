Lo que acelera
la indexación.

Una página no aparece en Google porque exista. Aparece porque alguien la descubre, la rastrea, la entiende y decide que merece estar. Esto es lo que acelera cada paso, en orden de impacto.

01 Que te encuentren

  • Una URL pública. HTTPS, sin login, sin contraseña. Si un robot no puede abrirla, no existe.
  • robots.txt abierto y con la línea Sitemap: apuntando al mapa. Un Disallow: / por error es la causa número uno de "no indexada".
  • sitemap.xml con URLs absolutas y lastmod real. Es la lista que le dices a Google de qué páginas tienes.
  • Enlaces internos. Cada página debe estar enlazada desde otra. Una página huérfana solo la encuentra el sitemap.
  • Enlaces externos. GitHub, LinkedIn, un foro, un comentario. Es lo que más pesa para que te descubran sin esperar al sitemap.

02 Para Google

  • Search Console, propiedad de dominio (por DNS) o de URL. Sin verificar no puedes pedir nada.
  • Enviar el sitemap en Indexación → Sitemaps. Tarda un día en procesarse.
  • Inspección de URL → Solicitar indexación para la página concreta. Hay cuota y repetirlo no acelera nada: se pide una vez.
  • Leer el motivo en Páginas. "Rastreada, actualmente no indexada" casi siempre significa contenido flojo, no un fallo técnico.
  • La Indexing API no vale para webs normales: solo para ofertas de empleo y directos.

03 Para Bing, Yandex y Naver

  • Bing Webmaster Tools: dar de alta el sitio, importando desde Search Console si quieres.
  • IndexNow: una clave en la raíz del sitio y un aviso por API cada vez que cambias algo. Rastrean en horas, no en días.
  • Google no usa IndexNow. Para Google sigue siendo sitemap y Search Console.

04 Que decidan indexarla

  • Contenido real. Una página con huecos se rastrea, pero no se indexa. Texto propio y útil es el requisito que no se puede saltar.
  • Título y descripción únicos, que digan de qué va la página y no una frase genérica.
  • HTML semántico: un solo h1, secciones con h2, enlaces con texto que se entienda.
  • Datos estructurados (JSON-LD): Person, WebSite, Article… Le dicen a la máquina qué es cada cosa.
  • Velocidad: estático, fuentes locales, sin scripts de terceros. Es gratis y se nota.
  • Móvil y HTTPS. Sin esto, el resto da igual.
  • Actualizar lastmod cuando cambias el contenido. Es la señal de "esto está vivo".

05 Lo que no acelera

  • Enviar la misma URL diez veces a Search Console. Hay cuota y no corre más.
  • Comprar enlaces o meterte en directorios basura. Puede penalizar.
  • Repetir la palabra clave hasta que el texto no se lea.
  • Texto oculto, redirecciones raras o contenido distinto para el robot.
  • Esperar que la Indexing API de Google haga algo. No aplica.
